Etiquetas Básicas de HTML

<!DOCTYPE html> - Define el tipo de documento HTML.
<html> - Indica el inicio del documento HTML.
<head> - Contiene información sobre el documento.
<title> - Establece el título de la página.
<meta> - Proporciona metadatos sobre el documento.
<link> - Vincula a hojas de estilo externas.
<style> - Define estilos CSS internos.
<body> - Contiene el contenido visible de la página.
<h1> - Define un encabezado de nivel 1.
<p> - Define un párrafo de texto.
<a> - Crea un enlace a otra página o recurso.
<img> - Inserta una imagen en la página.
<ul> - Crea una lista desordenada.
<ol> - Crea una lista ordenada.
<li> - Define un elemento de lista.
<div> - Define una sección genérica en el documento.
<span> - Define una sección en línea genérica.
<table> - Crea una tabla.
<tr> - Define una fila en una tabla.
<td> - Define una celda en una tabla.
</html> - Indica el final del documento HTML.
